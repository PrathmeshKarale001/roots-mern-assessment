Create `server/src/services/dashboard.service.js` per API-05 and D-04:
- Import `Employee` from `../models/Employee.js`, `Task` from `../models/Task.js`, `DEPARTMENTS`, `EMPLOYEE_STATUS`, `TASK_STATUS`, `TASK_PRIORITY`, `PRIORITY_RANKS`, `STATUS_TRANSITIONS`, `MAX_ACTIVE_TASKS_PER_EMPLOYEE` from `../constants/enums.js`, `getTodayUtcCalendarDate` from `../utils/dates.js`, and `buildOverdueMongoFilter`, `enrichTaskWithOverdue` from `../utils/overdue.js`.
- Implement `getDashboardMetrics(todayUtc = getTodayUtcCalendarDate())`:
  - Run parallel aggregations across Employee and Task models (zero client-side counting):
    1. `employeeAggregation`:
       - Total employees count.
       - Group by `status` to get counts for `Active`, `On Leave`, `Inactive`.
       - Group by `department` across all 5 departments (initialize all 5 with 0 so departments with 0 employees still appear).
    2. `taskAggregation`:
       - Total tasks count.
       - Group by `status` for `Todo`, `In Progress`, `Completed`, `Cancelled`.
       - Compute `activeTasks = (todoCount + inProgressCount)`.
       - Compute `completionRate = total > 0 ? Number(((completedCount / total) * 100).toFixed(1)) : 0`.
       - Count `overdueTasksCount` using `buildOverdueMongoFilter(todayUtc)`.
       - Group by `priority` for `Low`, `Medium`, `High`, `Critical` (initialize all 4 with 0).
       - Group by `department` across all 5 departments (initialize all 5 with 0).
    3. `workload`:
       - Query `Employee.find().select('_id employeeId fullName email department role status activeTaskCount leaveStart leaveEnd').sort({ activeTaskCount: -1, fullName: 1 }).lean()`.
       - Map to include `maxCapacity: MAX_ACTIVE_TASKS_PER_EMPLOYEE` (3) and `availableSlots: Math.max(0, MAX_ACTIVE_TASKS_PER_EMPLOYEE - doc.activeTaskCount)`.
    4. `overdueTasks`:
       - Query `Task.find(buildOverdueMongoFilter(todayUtc)).populate('assignee', 'employeeId fullName email department role status').sort({ dueDate: 1, priorityRank: -1 }).limit(10)`.
       - Enrich each task with `enrichTaskWithOverdue(doc, todayUtc)`.
    5. `recentTasks`:
       - Query `Task.find().populate('assignee', 'employeeId fullName email department role status').sort({ createdAt: -1 }).limit(6)`.
       - Enrich each task with `enrichTaskWithOverdue(doc, todayUtc)`.
  - Assemble and return the complete payload structure:
    ```js
    {
      employees: {
        total,
        active,
        onLeave,
        inactive,
        byDepartment: { Development: n, Design: n, QA: n, HR: n, Sales: n }
      },
      tasks: {
        total,
        todo,
        inProgress,
        completed,
        cancelled,
        overdue: overdueCount,
        activeTasks,
        completionRate,
        byStatus: { Todo: n, 'In Progress': n, Completed: n, Cancelled: n },
        byPriority: { Low: n, Medium: n, High: n, Critical: n },
        byDepartment: { Development: n, Design: n, QA: n, HR: n, Sales: n }
      },
      workload,
      overdueTasks,
      recentTasks
    }
    ```
- Implement `getSystemMeta()`:
  - Return:
    ```js
    {
      departments: DEPARTMENTS,
      employeeStatuses: EMPLOYEE_STATUS,
      taskStatuses: TASK_STATUS,
      priorities: TASK_PRIORITY,
      priorityRanks: PRIORITY_RANKS,
      validTransitions: STATUS_TRANSITIONS,
      maxActiveTasks: MAX_ACTIVE_TASKS_PER_EMPLOYEE
    }
    ```
